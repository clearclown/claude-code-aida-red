## Обзор

AIDA-RED — это **фреймворк защитного тестирования безопасности**, интегрирующийся с [claude-code-aida](https://github.com/clearclown/claude-code-aida). Пока AIDA фокусируется на **создании** приложений, AIDA-RED фокусируется на их **взломе**, чтобы найти уязвимости раньше злоумышленников.

**Ключевая инновация**: AIDA-RED использует **контейнеры Podman/Docker** с инструментами безопасности **Kali Linux**, оркестрируемые Claude Code. Claude не пишет атакующий код — он вызывает проверенные инструменты безопасности с открытым исходным кодом и анализирует их вывод.

### Философия

1. **Нулевое доверие**: Предполагаем, что каждый вход — это вектор атаки
2. **Без моков**: Атакуем работающий контейнер, а не изолированные функции
3. **Реальные инструменты**: Используем проверенные сканеры безопасности (nuclei, nikto, nmap), а не пользовательские эксплоиты
4. **Действенные отчёты**: Каждая находка включает шаги воспроизведения и рекомендации по исправлению

## Инструменты безопасности

AIDA-RED поставляется с предустановленными стандартными инструментами безопасности:

| Инструмент | Назначение | Сценарий использования |
|------------|------------|------------------------|
| **[nuclei](https://github.com/projectdiscovery/nuclei)** | Сканер уязвимостей на основе шаблонов | Обнаружение CVE, неправильных конфигураций |
| **[nikto](https://github.com/sullo/nikto)** | Сканер веб-серверов | Ошибки конфигурации сервера, устаревшее ПО |
| **[nmap](https://nmap.org/)** | Сетевой сканер | Обнаружение портов, определение сервисов |
| **[ffuf](https://github.com/ffuf/ffuf)** | Веб-фаззер | Перебор директорий, фаззинг параметров |
| **[sslscan](https://github.com/rbsec/sslscan)** | Анализатор SSL/TLS | Проблемы сертификатов, слабые шифры |
| **[sqlmap](https://sqlmap.org/)** | Детектор SQL-инъекций | Уязвимости баз данных (полная версия) |
| **[stress-ng](https://github.com/ColinIanKing/stress-ng)** | Стресс-тестер | Тестирование исчерпания ресурсов |

## Установка

### Предварительные требования

- **Podman** (рекомендуется) или **Docker**
- **Claude Code** с установленным плагином AIDA

```bash
# Установка Podman (Ubuntu/Debian)
sudo apt install podman

# Или Docker
sudo apt install docker.io
```

### Установка AIDA-RED

AIDA-RED включён в плагин AIDA. Отдельная установка не требуется.

```bash
# Проверка установки
/aida:red-status
```

### Сборка образа сканера

```bash
# Инициализация и сборка контейнера Kali-сканера
/aida:red-init

# Или использовать облегчённую версию (быстрее сборка, меньше инструментов)
/aida:red-init --lite
```

**Размеры образов:**
- Полный: ~2GB (включает sqlmap, ZAP CLI)
- Облегчённый: ~624MB (nuclei, nikto, nmap, ffuf, sslscan)

## Использование

### Быстрый старт

```bash
# 1. Соберите приложение с помощью AIDA
/aida "Создать REST API с аутентификацией пользователей"

# 2. Инициализируйте сканер AIDA-RED
/aida:red-init --lite

# 3. Запустите сканирование безопасности работающего приложения
/aida:red-assault --target http://localhost:8080

# 4. Просмотрите отчёт
/aida:red-report
```

### Команды

| Команда | Описание |
|---------|----------|
| `/aida:red-init` | Сборка контейнера Kali-сканера, создание сети |
| `/aida:red-assault` | Запуск сканирования безопасности цели |
| `/aida:red-status` | Показать состояние сканера и последние находки |
| `/aida:red-report` | Создать детальный отчёт об уязвимостях |
| `/aida:red-cleanup` | Удалить контейнеры и сеть |

### Параметры атаки

```bash
# Базовое сканирование (стандартная интенсивность)
/aida:red-assault --target http://localhost:8080

# Максимальная интенсивность (все инструменты)
/aida:red-assault --target http://localhost:8080 --intensity maximum

# Только определённые инструменты
/aida:red-assault --target http://localhost:8080 --tools nuclei,nikto

# Сканирование проекта AIDA (автоопределение работающих сервисов)
/aida:red-assault --target ../my-aida-project
```

### Уровни интенсивности

| Уровень | Инструменты | Длительность |
|---------|-------------|--------------|
| `minimum` | nuclei, health-check | ~1 мин |
| `standard` | nuclei, nikto, nmap, sslscan | ~5 мин |
| `maximum` | Все инструменты, включая ffuf, sqlmap | ~15 мин |

## Три Злодея (Персоны агентов)

AIDA-RED использует трёх специализированных агентов-«Злодеев» для различных векторов атак:

### The Joker (Логический фаззер)
Генерирует входные данные, которые «технически валидны, но логически разрушительны».
- Граничные значения, огромные нагрузки, Unicode-инъекции
- Состояния гонки, целочисленные переполнения
- Инструменты: `ffuf`, `nuclei` (шаблоны фаззинга)

### The Shadow (Взломщик безопасности)
Находит обходы авторизации и утечки данных.
- IDOR, повышение привилегий, манипуляции с JWT
- SQL-инъекции, обход аутентификации
- Инструменты: `nuclei`, `nikto`, `sqlmap`

### The Chaos (Разрушитель инфраструктуры)
Ломает окружение, а не только код.
- Сбои контейнеров, сетевые разрывы
- Исчерпание ресурсов, хаос-тестирование
- Инструменты: `stress-ng`, `nmap`

## Интеграция с AIDA

AIDA-RED автоматически интегрируется с рабочим процессом AIDA:

1. **Автоматический триггер**: Когда AIDA завершает работу (качественные ворота пройдены), AIDA-RED предлагает запустить сканирование безопасности

2. **Внедрение доказательств**: Находки записываются в `.aida/tdd-evidence/external-bugs/`, вызывая **провал** качественных ворот AIDA до исправления проблем

3. **Непрерывный цикл**: Исправление уязвимостей → Пересборка AIDA → Повторное сканирование AIDA-RED → Повтор до чистоты

```
Сборка AIDA завершена
        ↓
Сканирование AIDA-RED
        ↓
Уязвимости найдены? ─── Нет ───→ Готово!
        │
       Да
        ↓
Внедрение в доказательства AIDA
        ↓
Качественные ворота AIDA ПРОВАЛЕНЫ
        ↓
Разработчик исправляет проблемы
        ↓
Пересборка AIDA → Цикл
```

## Соображения безопасности

AIDA-RED предназначен для **защитного тестирования безопасности** ваших собственных приложений:

- Сканируйте только приложения, которыми владеете или имеете разрешение на тестирование
- Никогда не используйте на продуктивных системах без авторизации
- Результаты могут содержать ложные срабатывания — проверяйте находки вручную
- Некоторые инструменты (sqlmap) могут изменять данные — используйте с осторожностью
